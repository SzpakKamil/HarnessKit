The dark appearance mode for a screenshot.

## Overview

Use the `dark` case to indicate that a screenshot should be captured or rendered using the system's dark color scheme. This corresponds to a dark background with light foreground content, commonly used for low-light environments.

The raw value for this case is `"Dark"`.
