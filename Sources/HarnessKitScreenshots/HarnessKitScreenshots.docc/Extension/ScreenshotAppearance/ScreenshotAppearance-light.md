The light appearance mode for a screenshot.

## Overview

Use the `light` case to indicate that a screenshot should be captured or rendered using the system's light color scheme. This corresponds to a bright background with dark foreground content, matching the default appearance on most Apple platforms.

The raw value for this case is `"Light"`.
